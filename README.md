# Grassland microbial residues

This repository contains the R code used for the analyses reported in the manuscript:

**Microbial extracellular residues accumulate faster in mineral-associated organic matter than cellular residues during grassland restoration**

The study examines the partitioning and accumulation of microbial necromass carbon (MNC) and extracellular polymeric substances (EPS) between particulate organic matter (POM) and mineral-associated organic matter (MAOM) along a 40-year grazing-exclusion chronosequence.

## Code availability

R scripts for data processing, statistical analyses, and figure generation will be provided in this repository.

## Software

Analyses were conducted in R 4.3.3.
